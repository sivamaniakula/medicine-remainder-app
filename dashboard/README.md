# Caregiver Web Dashboard

React + Tailwind app for caregivers to link patients, manage medications, and view alerts.

## Setup

1. Make sure your backend (from Module 1 + Bundle A) is already running on `http://localhost:5000`.
2. Open this `dashboard` folder in VS Code (as a separate window/workspace from `backend`, or side-by-side).
3. Install dependencies:
   ```
   npm install
   ```
4. Start the dev server:
   ```
   npm run dev
   ```
5. Open the URL shown in the terminal — usually `http://localhost:5173`.

## Using it

1. **Register a caregiver account** on the login screen (or log in if you already registered one via Postman in Module 1 — same backend, same users).
2. **Link a patient** on the dashboard home page by entering their phone number. The patient must already exist as a `patient`-role user (register one via Postman if you haven't, using the same `/api/auth/register` endpoint with `"role": "patient"`).
3. Click into a patient to **add medications**, see **today's doses**, and their status.
4. Check the **Alerts** page for missed-dose and low-refill notifications generated by the backend's scheduler.

## Notes
- If the API calls fail with a network error, double-check the backend is running and `src/api/client.js` points to the right URL/port.
- This is a functional-first build — the Swiggy/Zomato-style visual polish pass (bottom sheets are already used for the add-medication modal, but animations, streak banners, etc.) comes in a later module.
